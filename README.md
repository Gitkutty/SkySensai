# SkySensAI
is an AI powered advisory system, that could improve traffic awareness, sequencing, and conflict detection at non towered airports

Using San Martin, CA (E16) as a case study, the proposed system uses available data from Common Traffic Advisory Frequency (CTAF), ADS-B and weather information as well as aircraft position data, predicted flight paths, traffic-pattern rules, runway geometry and local weather to identify potential conflicts, sequence arriving aircraft, and provide real-time advisory messages over CTAF.
